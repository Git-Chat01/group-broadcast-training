# 话术练习系统 — 设计文档

> 日期：2026-05-28 | 状态：待审核

## 一、产品定位

为团播主持新人提供一个**伴随成长的话术版本系统**。核心闭环：学习模板逻辑 → 参考示范话术 → 自己写版本 → 试读打磨 → 培训师批注 → 修改迭代。

与现有"培训模块"（学完标记完成）的区别：话术是**活的、持续迭代的**，每次修改生成新版本，保留成长轨迹。

## 二、覆盖场景（16个，4大分类）

### 开场环节（2个）
| ID | 场景 |
|----|------|
| st-opening | 开场拉数据 — 关注/点赞/灯牌/评论，挤进流量层级 |
| st-rules | 玩法规则介绍 — 扣1留/扣2换人、刺保偷踢怎么玩 |

### 血条PK（8个）
| ID | 场景 |
|----|------|
| st-assassin | 刺客/刀门 — 主播被刺，拉到2倍票数复活 |
| st-revive | 复活赛/背刺 — 5秒内被2倍票数再次推翻的反转 |
| st-protect | 保门/守护 — 刺激守护者上票，渲染"被需要" |
| st-steal | 偷塔 — PK倒计时最后时刻出手 |
| st-kick | 踢门/反踢 — 二/三倍数分数反踢 |
| st-pk-open | PK前期造势 — 开局30秒破蛋讨彩头 |
| st-pk-close | PK后期守塔 — 最后10秒生死一线 |
| st-streak | 十连展示/通关 — 连胜10轮，戴皇冠+独舞+感言 |

### 应急场景（3个）
| ID | 场景 |
|----|------|
| st-cold | 拉票冷场/无人上票 — 转场重带节奏 |

| st-crisis | 突发状况 — 黑粉带节奏、技术故障、违规预警 |

### 收尾+通用（3个）
| ID | 场景 |
|----|------|
| st-thanks | 谢榜 — 主播依次感谢支持者，记大礼物详情 |
| st-signoff | 下播预告+导流 — 预告下次内容，引导关注/粉丝群 |

## 五、UI 设计

### 5.1 场景列表页（话术练习 Tab）

- 顶部概要："已完成 N/16 · 培训师已批 N 个"
- 4 个分类手风琴折叠，默认展开第一个
- 每项显示：场景名 + 状态标记（○未写 / ◐草稿 / ✓已写 / 🔴有批注）
- 分类头显示进度（如"开场环节 2/2"）
- 行高 ≥48px，触摸区域充足
- 手风琴交互：同时只保持一个展开（复用能力清单逻辑）

### 5.2 场景详情页

从上到下依次展示（正常滚动）：

1. **目的** — 一句话，简洁
2. **逻辑思维** — 教 WHY，较长文本
3. **示范话术** — 1-3 条，左右滑动切换
4. **关键技巧** — 列表
5. **培训师批注** — 左侧彩色边框高亮（仅当有批注时显示）

底部固定栏（不随内容滚动）：
- 多行输入框（默认 3 行高度，可手动拖拽拉高）
- 「保存草稿」按钮（灰色弱化）
- 「提交给培训师」按钮（主色强调）
- 「试读」按钮（进入大字纯文本模式）

### 5.3 试读模式

点击「试读」后弹出一个全屏大字层：
- 深色背景，白色大字（字号 ~20px），行间距大
- 仅显示"我的版本"当前内容
- 底部一个「关闭」按钮
- 无录音、无存储，纯辅助朗读

### 5.4 版本切换

顶部栏右侧「版本 N ▼」下拉，可切换到历史版本查看或回退。当前激活版本标记「当前」。

### 5.5 培训师端

新人监管中每个新人卡片新增一行统计：

```
话术进度：8/16 已写 · 3 个待批注
```

点击进入该新人的话术场景列表（和新人端一样的列表视图），点进场景看到新人"我的版本"+ 批注输入框。

## 六、关键交互规则

| 规则 | 说明 |
|------|------|
| **版本链** | 每次保存生成新版本号递增，不覆盖旧版 |
| **批注挂版本** | 培训师批注绑定到具体版本，修改后新版本批注重置 |
| **草稿自动保存** | 输入框内容在切换场景/退出时自动保存为草稿 |
| **提交才通知** | 只有点击「提交给培训师」后，培训师端才显示"待批注" |
| **模板更新不影响** | DATA_VERSION 升级合并模板，用户话术数据不受影响 |
| **触摸目标** | 所有可点击元素 ≥44px，间距 ≥8px |

## 七、移动端适配

- 基础设备宽度：375-430px
- 列表项最小高度 ≥48px
- textarea 最小高度 5 行（约 160px）
- 固定底栏高度约 56px（不含输入框展开）
- 试读模式字号 ≥18px，行高 1.8
- 按钮间距 ≥12px，避免误触
- CSS 响应式断点：≤600px（主流手机）、≤380px（极小屏）— 与现有体系一致

## 八、验收标准

1. 新人端 4 个 Tab 正常切换，话术练习在第三位
2. 16 个场景按 4 个分类手风琴折叠，默认展开第一个
3. 每个场景的目标、逻辑思维、示范话术、关键技巧完整展示
4. 示范话术支持左右滑动切换
5. 底部固定输入栏始终可见，可保存草稿、可提交
6. 试读模式大字展示，深色背景
7. 版本历史可查看，可切换
8. 培训师端可查看每个新人的话术版本，可填写批注
9. 新人端列表页正确显示 ○/◐/✓/🔴 四种状态
10. 手机端（375px 宽度）所有触摸目标 ≥44px，无横向溢出

## 九、16个场景的话术内容（待填充）

话术模板的内容质量是本系统的核心。示范话术需要满足：
- 自然不做作，有"人味"而非 AI 感
- 娱乐化而非官方化，不给游客压力
- 情商在线，用词斟酌
- 底层逻辑清晰，能教新人 WHY

内容需逐场景编写，作为独立迭代推进。
