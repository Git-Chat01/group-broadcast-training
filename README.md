# 团播主持新人培训系统

> 版本 v1.0 | 2026-05-27 | 纯前端单页面应用

## 项目概述

面向团播（团队直播）行业的新人主持培训系统。新人主持通过浏览器访问，完成培训知识复习和试卷考核；培训师在后台管理题库内容并查看新人的学习进度。

## 角色与入口

| 角色 | 入口方式 | 功能范围 |
|------|---------|---------|
| 新人主持 | 输入艺名即可进入 | 浏览培训模块、参加试卷考试、查看个人进度 |
| 培训师 | 点击底部「培训师管理」输入密码 | 管理培训内容和题库、查看所有新人学习数据 |

默认管理密码：`xsx2001..`（可在后台修改）

## 快速开始

1. 双击打开 `group-broadcast-training/index.html`
2. 新人：输入艺名 → 点击「进入学习」
3. 培训师：点击页面底部「培训师管理」→ 输入密码 → 进入后台

## 功能清单

### 新人端

- **培训模块**：浏览培训内容（支持图文混排和视频嵌入），标记完成状态，学完后可选择参加关联考试
- **试卷考试**：查看所有可用试卷及历史成绩，进入答题（支持单选/多选/判断/填空/图片题），提交后自动批改出分，错题附带解析回顾
- **我的进度**：查看模块完成数/考试通过数/平均分/历史考试成绩记录

### 培训师端

- **内容管理**：新增/编辑/删除培训模块和试卷，JSON 格式编辑题目，从 Word/Excel 文件导入题库
- **新人监管**：查看每位新人的模块完成状态和考试成绩记录，可删除新人数据
- **密码管理**：修改管理后台登录密码

## 技术栈

- 纯 HTML/CSS/JavaScript，零框架依赖
- localStorage 数据持久化
- 导入功能依赖 CDN（JSZip + SheetJS）

## 使用说明

### 导入题库

1. 以培训师身份登录后台
2. 点击「导入题库」按钮
3. 填写试卷标题和 ID
4. 选择问卷星导出的 .docx 或 .xlsx 文件
5. 预览确认后点「确认导入」

### 手动编辑试卷

1. 在培训师后台点击试卷旁的「编辑」按钮
2. 按 JSON 格式编辑题目数据
3. 题目格式参考：

```json
{
  "id": 1,
  "type": "single",
  "question": "题干文字",
  "images": [],
  "options": ["A. 选项A", "B. 选项B"],
  "answer": [0],
  "explanation": "解析说明"
}
```

### 添加图片

将图片放入 `images/` 目录，在题目的 `images` 字段中填写相对路径即可。

## 注意事项

- **首次使用前**：如页面空白，请打开浏览器控制台（F12）执行 `localStorage.clear()` 后刷新
- **数据存储**：数据存储在浏览器 localStorage 中，清除浏览器数据会导致数据丢失
- **导入功能**：需要联网（加载 JSZip 和 SheetJS 的 CDN）
- **浏览器兼容**：建议使用 Chrome / Edge 最新版本
